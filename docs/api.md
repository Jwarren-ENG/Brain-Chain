# API reference

Base URL: `http://localhost:8000/api`. Interactive OpenAPI docs at
`http://localhost:8000/docs` (generated by FastAPI, always current).

Authentication: `Authorization: Bearer <token>` from `POST /auth/login`. Errors are
structured `{"detail": ...}` with correct status codes (401 unauthenticated,
403 role denied, 404 not-found-or-unauthorized, 409 conflict, 422 validation).
List endpoints paginate with `limit`/`offset` and return `total` where applicable.

## Auth
| Method | Path | Notes |
|---|---|---|
| POST | `/auth/login` | `{email, password}` → token + user (roles, clearance) |
| POST | `/auth/logout` | revokes the session |
| GET | `/auth/me` | current user |

## Knowledge
| Method | Path | Notes |
|---|---|---|
| GET | `/documents` | permission-filtered; filters: `q, doc_type, department_id, data_source_id, classification_level, project`; paginated |
| GET | `/documents/{id}` | detail incl. versions, chunks, lineage, `access_reasons`; 404 if unauthorized |
| GET | `/search` | hybrid/keyword/semantic; each result carries excerpt, score, `access_reasons` |
| GET | `/filters` | filter options scoped to the caller's accessible corpus |
| GET | `/entities` · `/entities/{id}/graph` | knowledge-graph browse |
| GET | `/meetings` · `/decisions` | tribal knowledge; transcript-gated by document ACL |

## Feedback & surveys
| Method | Path | Notes |
|---|---|---|
| POST | `/feedback` | named/confidential/anonymous; anonymous → receipt token, no id |

## Agents, tasks, approvals

## Brain Interviews
| Method | Path | Notes |
|---|---|---|
| POST | `/interviews` | Create session (`mode`, `purpose`, `visibility`, optional context). Voice + anonymous → 422, no record. Returns the receipt token once. |
| GET | `/interviews` | Caller's named+confidential sessions (anonymous structurally absent) |
| GET | `/interviews/{id}` | Owner or `?receipt=`; everyone else 404 (incl. managers/admins) |
| DELETE | `/interviews/{id}` | Full deletion propagation (transcript, artifacts, audio, published docs/chunks/citations, feedback, proposed decisions, open tasks) |
| POST | `/interviews/{id}/start` | draft → active (text) or consent_required (voice); returns the opening question |
| POST | `/interviews/{id}/consent` | Voice only; records consent + audio retention choice |
| POST | `/interviews/{id}/turns` | Employee answer → interviewer envelope (message, question, reason, can_complete, sensitive_warning) |
| PATCH | `/interviews/{id}/turns/{turn_id}` | Correct an answer/transcript line before completion |
| POST | `/interviews/{id}/voice-chunk` | Transcription adapter (deterministic mock locally; supports failure simulation) |
| POST | `/interviews/{id}/pause` · `resume` · `switch-to-text` | Voice lifecycle |
| POST | `/interviews/{id}/complete` | active/paused → processing → review_required (extraction) |
| POST | `/interviews/{id}/retry` | Recover from failed |
| GET | `/interviews/{id}/artifacts` · PATCH `…/artifacts/{aid}` | Review: include/exclude, edit summary, mark uncertain |
| POST | `/interviews/{id}/publish` | review_required only (409 otherwise); transactional routing; returns destinations |
| POST/GET | `/interview-assignments` | Managers request interviews (one person or a department); employees list requests addressed to them. Individual requests can't be answered anonymously; department requests report aggregate counts only. |
| GET | `/interview-assignments/targets` | manager/executive: addressable people + departments |
| POST | `/interview-assignments/{id}/decline` · `cancel` | Employee declines (a request is not an order) / creator cancels |
| GET | `/meetings/{id}/topics` | Published meeting-prep topics (attribution only for named sessions) |
| POST | `/decisions/{id}/confirm` | manager/executive; proposed → active |
